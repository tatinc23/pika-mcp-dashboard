# Pika MCP Dashboard

A live, GitHub Pages-hosted visual dashboard for all Pika Labs MCP tools and skills.

🔗 **Live URL:** https://tatinc23.github.io/pika-mcp-dashboard

## Features

- 42 tools pulled from the official Pika-Labs/Pika-Plugins tools-manifest.json
- 3 skills (explainer, podcast, ugc-ads) with full parameter schemas
- 6 category sections: Generate Video, Image & Music, Edit & Effects, Voice & Audio, Identity, Utilities
- Quick Run modal — click any tool or skill card → guided form → generates exact command
- Search (⌘K), category filter pills, dark/light mode toggle
- Docs & Setup page — install steps, .mcp.json config reference, full 42-tool reference table

## Enable GitHub Pages

1. Go to Settings → Pages
2. Branch: `main` → Folder: `/ (root)` → Save
3. Live at `tatinc23.github.io/pika-mcp-dashboard`

## Local Dev

```bash
python3 -m http.server 8080
# Open http://localhost:8080
```
