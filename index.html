🚀 Quick Setup

1. Install Pika MCP

claude mcp install pika-labs/pika-plugins

2. Or add to .mcp.json manually

{ "mcpServers": { "pika": { "command": "npx", "args": ["-y", "@pika-labs/mcp"], "env": { "PIKA_DEV_KEY": "your_key_here" } } } }

3. Verify in Claude Code

/mcp # pika should appear as connected

⚡ Skills Setup

Skills are autonomous multi-step workflows. Install them by adding the skill folder to your project's .claude/skills/ directory.

git clone https://github.com/Pika-Labs/Pika-Plugins.git cp -r Pika-Plugins/skills/* .claude/skills/ # /pika:podcast — two-host dialogue video from topic or URL # /pika:explainer — 65-80 sec explainer from a URL # /pika:ugc-ads — 15 sec vertical UGC ad from a product URL

📎 Attaching Images

Skills that accept image inputs work through Claude Code's standard file attachment. Drag images into the Claude Code terminal or IDE, or provide a publicly hosted HTTPS URL as a parameter.
