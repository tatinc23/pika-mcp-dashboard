🚀 Connect to the MCP

Get access to your Pika Agent's identity, plus all creative models — Seedance 2.0, GPT Images 2.0, and more.

1
Open Claude Settings

Launch the Claude app or open claude.ai and go to:

Settings → Connectors
2
Add a Custom Connector

Name it Pika and paste this URL:

https://mcp.pika.me/api/mcp
3
Connect and Sign In

Select Add → Connect and create your Pika account. Then ask Claude to adopt their new identity.

Set up your Pika identity through the MCP
1
Add the MCP

Run this in your terminal once:

claude mcp add pika --transport http https://mcp.pika.me/api/mcp
2
Sign In

Inside Claude Code, run /mcp and follow the OAuth flow to log in to Pika:

/mcp
3
Try a Prompt

Once signed in, ask Claude to set up your Pika identity:

Set up your Pika identity through the MCP

⚡ Install the Pika Skills Plugin

Unlocks 9 curated /pika:* slash commands — Podcast, Explainer, UGC Ads, Baseball Trend, Kiss Cam, App Sizzle, App Store Screens, Build a Brand, and Founder Product Video. Use this dashboard to build the exact command, then run it in Claude Code.

1
Add the Plugin from Marketplace

In Claude desktop or Cowork, open Customize → Personal plugins (+) → Create plugin → Add marketplace, then paste this handle and click Sync:

Pika-Labs/Pika-Plugins
2
Toggle the Plugin On

Once added, in the Customize page open the Personal plugins tab and toggle the Pika plugin on.

Pika 🟢
3
Run any of the 9 Skills

Use this dashboard to build the exact command, then paste it in. Or invoke directly:

/pika:podcast
/pika:ugc-ads
/pika:build-a-brand
/pika:founder-product-video
1
Add the Marketplace

Inside Claude Code, run:

/plugin marketplace add Pika-Labs/Pika-Plugins
2
Install the Pika Plugin

Then install the plugin from the marketplace:

/plugin install pika@pika-plugins
3
Run any of the 9 Skills

/pika:podcast
