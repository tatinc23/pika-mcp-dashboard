🚀 Quick Setup

1. Install the Pika MCP plugin

claude mcp install pika-labs/pika-plugins

2. Or configure .mcp.json manually

{ "mcpServers": { "pika": { "command": "npx", "args": ["-y", "@pika-labs/mcp"], "env": { "PIKA_DEV_KEY": "your_key_here" } } } }

3. Verify connection in Claude Code

/mcp # You should see pika listed as connected

📚 Skills Setup

Skills are autonomous workflows that Claude follows. Install them by adding the skill folder to your .claude/skills/ directory.

# In your project root: git clone https://github.com/tatinc23/Pika-Skills-TAT.git cp -r Pika-Skills-TAT/skills/* .claude/skills/ # Available skills: # /pika:podcast — AI podcast generation # /pika:explainer — Explainer video creation # /pika:ugc-ads — UGC ad generation
